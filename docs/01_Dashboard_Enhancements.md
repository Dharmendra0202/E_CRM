# Dashboard Enhancements

## Goal
Implement real-time dashboard widgets with no dummy data.

## Features
- Pending Student Fees widget
- Pending Staff/Teacher Salary widget
- Batch-wise attendance (students, teachers, staff)
- Dynamic greeting based on server time

## Requirements
- Clicking pending fees opens detailed student list.
- Clicking pending salaries opens detailed employee list.
- Use actual enrollment, fee, and payroll data.
- Remove Average Attendance widget.
